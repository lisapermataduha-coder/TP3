Character Manager adalah program sederhana yang dibuat menggunakan bahasa pemrograman Java untuk membuat dan menampilkan data karakter. Program ini memiliki fitur untuk menaikkan level karakter (level up), mengatur mana, dan memeriksa apakah karakter masih hidup menggunakan method isAlive().
